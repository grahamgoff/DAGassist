# DAG behind [toy_data](https://grahamgoff.com/DAGassist/reference/toy_data.md)

The graph used to simulate
[toy_data](https://grahamgoff.com/DAGassist/reference/toy_data.md), with
`X` marked as the exposure and `Y` as the outcome. Pass it directly to
[`DAGassist()`](https://grahamgoff.com/DAGassist/reference/DAGassist.md).

## Usage

``` r
toy_dag
```

## Format

A `dagitty` object with 7 nodes.

## Source

Defined in `data-raw/make_data.R`.
